# Plotly renderer

`plotly.min.js` is Plotly.js 3.7.0, distributed with plotly.py 6.9.0.
Source: https://github.com/plotly/plotly.js/tree/v3.7.0

The original distribution header is retained. `LICENSE.txt` is the MIT license
included in the plotly.py distribution. The renderer is bundled locally so saved
Plotly JSON can display without launching Python or accessing a CDN.
