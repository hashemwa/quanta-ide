# KaTeX

`katex.min.js` is the unmodified KaTeX 0.16.22 npm distribution, licensed under
the included MIT license. Source: https://github.com/KaTeX/KaTeX/tree/v0.16.22

Notebook exports use JavaScriptCore to produce static MathML with `trust: false`
and bounded macro expansion. Exported equations need no network, scripts, fonts,
or Python environment. https://katex.org/docs/options
